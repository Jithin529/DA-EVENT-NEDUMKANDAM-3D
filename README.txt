DA EVENTS 3D STUDIO - ANDROID APP PROJECT

This is an Android Studio project that wraps the DA EVENTS 3D Studio prototype in an Android WebView.

HOW TO BUILD AN APK:
1. Install Android Studio on a computer.
2. Open this extracted folder as an existing Android Studio project.
3. Allow Gradle sync and install the Android SDK Platform 35 if prompted.
4. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the APK location, usually app/build/outputs/apk/debug/app-debug.apk.

IMPORTANT:
- This ZIP is Android source project, NOT a compiled APK.
- A compiled APK cannot be produced in this environment because Android SDK/Gradle build tools are not installed.
- Internet is required by the current prototype to load Three.js from its CDN.
- This is a prototype; do not distribute as a production app until tested on target devices.
